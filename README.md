# Mirador

Explorador y visor de fotos y vídeos para memorias USB y tarjetas SD en Android.

- Navega por las carpetas del pendrive (USB‑C u OTG) en lista o cuadrícula con miniaturas.
- Visor de fotos con zoom nítido, rotación y paso entre fotos deslizando.
- Reproductor de vídeo y audio integrado: velocidad, gestos, avance rápido y zoom.
- Vista múltiple: dos fotos o dos vídeos lado a lado, con zoom y reproducción sincronizados.
- Copiar, mover, renombrar y eliminar archivos.
- Abre fotos y vídeos desde otras apps («Abrir con Mirador»).

Requiere Android 8.0 o superior.
